# Changelog

Every Gox release, **newest first**, one row per version, each with its **release date**, **tags** (what that release
mainly touched) and a link to the **GitHub Release**. Version numbers are anchor links
(`/en/release/changelog#v0-27-0`), so entries are easy to cite from issues and PRs.

Only **shipped versions** appear here. For one-line summaries of the last few releases, see [Latest release](/en/release/).

::: tip How to read the table
- **Dates** come from GitHub Releases (Asia/Shanghai). Releases up to 2026-11-06 shipped without a body, so their dates
  follow the release cadence and the leading "what landed that day" sentence is reconstructed from the version context —
  it is **not** the original release note.
- **Tags** are grouped by this site; a release can carry several. `cadence` means the version number moved and engine
  code did not change.
- Numbered ①②③ inside a long entry are **parallel change clusters** in the same release, not sequential steps.
:::
